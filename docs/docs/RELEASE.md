CopyFlash 闪拷 0.1.0 预览版：选中文字照常复制，在可取得选区位置的软件中短暂反色；无法定位时显示简短提示。

- Windows 10 / 11 x64 目标，依赖系统 .NET Framework 4.8。
- 免安装托盘程序，默认 300 ms，可暂停或调整为 600 / 900 ms。
- 不接管 Ctrl+C，不读取或保存剪贴板正文，不联网；反色所需的选区像素仅在内存中临时处理。
- 运行 `CopyFlash.exe --demo` 可打开实验窗口。
- 兼容性因软件而异。请在报告问题时提供软件名称、版本、显示缩放和“反色 / 仅提示 / 无反馈”的现象。
- 当前为无代码签名的实验构建。基础算法和监听自检不等于全应用兼容验证。

具体测试范围以仓库 `docs/VALIDATION.md` 为准。
