# 验证记录

日期：2026-10-19（北京时间）。版本：0.1.0，Windows 本机预览。

## 已完成

- 用本机 .NET Framework x64 编译器成功生成 exe。
- `--self-test` 退出码 0：RGB 反色、矩形裁剪与去重、无效坐标过滤、800 万像素上限、Windows 剪贴板监听注册与注销。
- 在交互桌面打开本程序的原生 RichTextBox 实验窗口，用键盘实际执行 Ctrl+A、Ctrl+C。
- 完成处理后，原生状态控件显示“原文反色 · 4 个选区矩形 · 300 ms”。这验证了剪贴板通知、UI Automation 辅助进程、矩形返回和浮层创建路径。
- 复制后键盘焦点仍在实验文字区；用 Tab 导航到粘贴验证区，实际按 Ctrl+V，验证区出现与源实验区一致的文字。
- 原生暂停开关可切换，状态控件显示“已暂停”；重新启动时为“已启用 · 等待复制”。
- 最终构建复测 Ctrl+A / Ctrl+C，取得 4 个选区矩形；用退出按钮的 Alt+X 快捷键退出，窗口消失，随后可正常重新编译同一个 exe。
- 本次桌面截图接口两次超时，未取得可复核的原生窗口截图；没有声称已完成原生像素截图验收。

## 独立网页原型

开发前的网页交互原型曾在本机 Edge 自动化中验证：Ctrl+C / Ctrl+V、跨行选区、连续复制、300–1400 ms 调整、深浅主题、窄屏无横向溢出。**这些结果仅属于网页原型，不作为 Windows 全局兼容测试。**
